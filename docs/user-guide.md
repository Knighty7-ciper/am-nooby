# User Guide

## Welcome to NoobBlog! 🚀

This guide will help you get started with creating amazing content on NoobBlog.

## Getting Started

### Creating Your Account

1. Visit your deployed site (e.g., `https://your-site-name.netlify.app`)
2. Click "Get Started" or "Sign Up"
3. Enter your details:
   - Email address
   - Username (this will be your @username)
   - Password
4. Verify your email
5. Complete your profile

### Setting Up Your Profile

1. Click your avatar in the top right
2. Select "Profile"
3. Add:
   - Profile picture
   - Bio (tell readers about yourself)
   - Social media links
   - Website
   - Location

## Writing Your First Post

### Step 1: Start Writing

1. Click "Write" button in the header
2. You'll see the editor interface

### Step 2: Craft Your Content

#### Title
- Make it catchy and descriptive
- 50-60 characters works best
- Include main keyword

#### Cover Image
- Use high-quality images
- Recommended size: 1200x630px
- Free sources: Unsplash, Pexels

#### Excerpt
- Brief summary (150-160 characters)
- Hook readers to click
- Appears in previews

#### Content
Use our rich text editor with:
- **Bold**, *Italic*, ~~Strikethrough~~
- Headings (H1, H2, H3)
- Lists (bullet and numbered)
- Quotes
- Code blocks
- Images
- Links

### Step 3: Optimize

#### Add Tags
- Use 3-5 relevant tags
- Help readers discover your post
- Examples: `javascript`, `tutorial`, `webdev`

#### SEO Settings
- Meta title (if different from title)
- Meta description
- Keywords

### Step 4: Publish

**Save as Draft**
- Saves your progress
- Only you can see it
- Edit anytime

**Publish**
- Makes post public
- Sends to followers
- Appears in feeds

## Editor Features

### Keyboard Shortcuts

- `Ctrl/Cmd + B` - Bold
- `Ctrl/Cmd + I` - Italic
- `Ctrl/Cmd + K` - Add link
- `Ctrl/Cmd + Z` - Undo
- `Ctrl/Cmd + Shift + Z` - Redo

### Markdown Support

You can also use Markdown:

```markdown
# Heading 1
## Heading 2
### Heading 3

**Bold text**
*Italic text*

- Bullet list
1. Numbered list

> Quote

`inline code`

```code block```
```

### Adding Images

1. Click image icon in toolbar
2. Enter image URL
3. Or upload from computer
4. Add alt text for accessibility

### Adding Links

1. Select text
2. Click link icon
3. Enter URL
4. Press Enter

## Troubleshooting

### Can't Publish Post

**Issue**: "Publish" button disabled
**Solution**: Ensure title and content are filled

### Images Not Showing

**Issue**: Broken image links
**Solution**: 
- Use direct image URLs
- Ensure URL is publicly accessible
- Try different image host

### Formatting Issues

**Issue**: Text looks wrong
**Solution**:
- Refresh page
- Clear browser cache
- Try different browser

### Lost Draft

**Issue**: Can't find saved draft
**Solution**: Check Dashboard → Drafts section
